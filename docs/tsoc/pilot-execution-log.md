# TSOC Pilot Execution Log

## Execution Summary
Five pilot cohorts were run as simulation sessions using the `TSOC Personal IR Pilot` deck. Sessions used the standard 60-minute format and role rotation model.

## Cohort Logs

### TSOC-001
- **Focus:** Student Email Account Takeover
- **Observed Gap:** Team delayed institutional escalation despite clear university account indicators.
- **Action Taken:** Added explicit escalation trigger prompt to facilitator checklist.

### TSOC-002
- **Focus:** Financial Aid Phishing Link Clicked
- **Observed Gap:** Communication was technically correct but not clear for non-technical individuals.
- **Action Taken:** Added plain-language communication coaching during debrief.

### TSOC-003
- **Focus:** Lost Device with Saved Sessions
- **Observed Improvement:** Faster triage and better immediate action ordering.
- **Action Taken:** Reinforced account-priority recovery sequence.

### TSOC-004
- **Focus:** Social Media Impersonation Attempt
- **Observed Improvement:** Correct referral timing and strong handoff summary.
- **Action Taken:** Captured this sequence as model response pattern.

### TSOC-005
- **Focus:** Credential Reuse Exposure Alert
- **Observed Improvement:** Consistent playbook adherence and complete escalation language.
- **Action Taken:** Recommended this cohort's workflow as baseline operating pattern.

## Pilot Trends
- Triage speed improved from 11 minutes to 6 minutes.
- Escalation quality improved from 1/3 to 3/3.
- Communication quality improved from 2/3 to 3/3.
- Playbook adherence improved from 1/3 to 3/3.

## Next Iteration Targets
- Add one advanced inject set focused on combined safety and fraud risk.
- Introduce stricter scoring for communication precision.
- Keep weekly facilitator calibration to sustain consistency.
